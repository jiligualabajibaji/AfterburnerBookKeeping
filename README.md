# 极速记账 (AfterburnerBookKeeping)

一款基于 Flutter 的记账 Android 应用，同时涵盖手动记账与 AI 记账双模式。从需求分析、UI 设计、功能迭代到 APK 发布，全部通过 AI 对话驱动完成，累计迭代 206 项需求。

## 功能

- **手动记账**：支出/收入快速录入，金额支持算式（`100+50`）和中文数字（`一百三十六`、`一块二毛七`）；支持再记一笔连续录入；日期可选附带时间、左右滑动切换上/下一天；数量/单位记录（步进器 + 单位下拉选择）；批量多选删除（全选本月/全选某天支出/全选某天收入）
- **数量/单位**：数量步进器（`[-] 输入框 [+]`），支持小数、不允许负数；单位下拉选择；长按提示进入设置，可调整步长、默认单位、默认数量，单位列表支持拖拽排序、删除、新增
- **AI 记账**：自然语言描述自动解析，支持规则引擎与 LLM（DeepSeek 等）双模式；规则引擎识别金额、日期（昨天/后天/大前天等）、分类；LLM 支持多 API 配置预设、请求取消、详细中文错误提示
- **搜索**：按关键词搜索类别、备注、金额，支持字段筛选（类别/备注/金额，可多选，默认全选）；支持日期范围筛选和支出/收入类型筛选，结果按日期分组
- **统计**：月度/年度收支饼图（暖色系支出、绿色系收入），精确到小数点后两位
- **流水**：左右滑动切换月份，按日期分组展示，每天收支合计，月度汇总
- **自定义分类**：支出/收入分类独立管理，长按重命名/删除/拖拽排序，默认金额/备注，同名查重，兜底分类加锁保护
- **数据管理**：JSON 导出/导入，支持跨设备迁移
- **个性化**：主题切换（浅色/深色/跟随系统）、中英文语言切换、自定义背景图、自定义软件名称、多 API 配置预设
- **品质保障**：Flutter integration_test 集成测试覆盖 13 条核心业务流程
- **无云依赖**：本地 SQLite 存储，数据完全离线

## 技术栈

Flutter + Dart + SQLite（sqflite）
