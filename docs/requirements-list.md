# 记账 Agent — 需求清单

1. 做一个记账Android应用，包含手动记账和自然语言AI记账功能，使用Python
2. 选择方案B（Flutter + Python引擎）
3. 无需登录和云功能，支持账单导入导出及跨手机迁移
4. 支持日常流水记账（餐饮、交通、购物），月底查看统计
5. 先实现文字输入，语音输入后面再添加
6. AI解析后弹窗确认
7. 本地规则解析 + 可选大模型AI解析
8. 需要正常的记账软件功能：选择类别、添加描述、填写金额、保存/修改
9. 用户可以自定义添加和删除类别
10. 只记录人民币，支持收入和支出
11. 日期选择器可选年月日或精确到时分秒
12. AI解析缺失字段时向用户询问补全
13. 设置中添加主题、字号选择
14. 点击具体记录可编辑
15. 删除分类后该分类下的账单统一归入"其他"类别，且"其他"不可删除
16. 添加支出和收入时分类直接显示在屏幕上半边，无需二级菜单
17. 1分钟无操作自动退出到桌面
18. 统计界面包含支出和收入统计，AI解析的数据也计入
19. 支持自定义图标，软件名称可修改
20. AI解析支持汉字数字（如"三十八"）
21. 设置中可上传图片作为软件图标，保留最多10个历史图标
22. 加快应用启动速度，减少黑屏时间
23. 统计支出饼图用暖色系，收入饼图用绿色系
24. 上传图片支持裁剪，但不改变桌面图标
25. 点击记录编辑时四周发光，收入发绿光、支出发红光
26. 统计界面添加年度统计
27. 记一笔页面：右上角"再记一笔"（保存并继续），右下角"保存并返回"
28. 记一笔页面根据支出/收入切换红/绿色系
29. 记一笔页面默认选中第一个分类，设置中可调整分类顺序
30. 主界面右下角设置绿色收入+和红色支出-两个按钮，大小为原来的1.5倍
31. 上传图片崩溃问题修复，添加删除已上传图片功能
32. 设置分类管理中支出和收入隔离显示
33. 左滑记录显示删除按钮
34. 统计界面修复年度支出/收入统计不准确的问题
35. 统计界面点击月份或年份弹出选择器
36. 记录编辑改为单击，长按不做任何操作
37. 分类管理中"其他"去重并改为"其他支出"/"其他收入"，不可删除
38. 统计界面年月选择器只选年月，不选具体日期
39. 支持批量删除，可全选本月/本月支出/本月收入
40. 优化左滑删除的响应速度
41. 在编辑界面添加"再记一笔"功能
42. 记一笔时如果不在当月，默认日期设为该月1号
43. 应用名改为"极速记账"
44. API配置支持保存多组配置并切换，标注当前使用中的配置
45. 规则解析兼容省略"钱"、"元"字眼和末尾标点符号
46. 规则解析支持"昨天""大前天"等相对日期
47. 大模型解析支持取消操作
48. 大模型解析的内容修改后才能保存，修复直接保存无效的问题
49. 支持自定义软件名，30字符以内
50. 主界面左右滑动切换月份，点击年月文字跳转到指定月份
51. 主界面日期后的"+"按钮添加当天记录
52. 主界面切换标签页后回到之前浏览的月份

54. 金额支持加减算式（如100+50），结果小于0弹出提示

60. 设置中去除分类管理功能

66. API配置默认接口地址设为https://api.deepseek.com
