# 记账 Agent 设计文档

## 概述

一个 Android 记账应用，支持手动记账和 AI 自然语言录入，数据本地存储，支持设备间文件迁移。

## 技术路线

| 层 | 技术 |
|---|---|
| UI 层 | Flutter (Dart) |
| 桥接层 | Android Kotlin + Chaquopy |
| AI 解析引擎 | Python |
| 数据库 | SQLite（Flutter drift） |
| 数据迁移 | JSON 文件 |

## 架构

```
Flutter App (UI + SQLite)
    │ MethodChannel
Android 原生层 (Kotlin + Chaquopy)
    │
Python 解析引擎
    ├── 规则解析器（正则 + 关键词）
    └── AI API 客户端（Claude/GPT）
```

Flutter 负责全部 UI 和本地数据存储。Python 只负责自然语言解析，通过 Chaquopy 嵌入 Android 原生层与 Flutter 通信。

## 数据模型

### categories（分类表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | 自增主键 |
| name | TEXT | 分类名称，如"餐饮"、"交通" |
| icon | TEXT | 图标标识 |
| type | TEXT | expense / income |
| sort_order | INTEGER | 排序序号 |

**预置分类：** 餐饮、交通、购物、娱乐、住房、医疗、其他支出、工资收入、其他收入

用户可以自由增删改分类。

### transactions（账单表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | 自增主键 |
| amount | REAL | 正值=收入，负值=支出 |
| category_id | INTEGER FK | 关联 categories.id |
| note | TEXT | 备注（AI 录入时存原始描述） |
| timestamp | INTEGER | 时间戳，可精确到秒或仅到日期 |
| created_at | INTEGER | 创建时间 |
| updated_at | INTEGER | 修改时间 |

## 页面结构

共 5 个页面：

### 1. 首页：账单流水列表
- 按月筛选，显示当月总收支
- 按日期分组展示流水条目
- 每天显示：分类图标+名称、金额、备注、时间
- 浮动按钮"记一笔"

### 2. 记一笔（手动录入）
- 表单：金额、分类（下拉）、备注、日期（可选展开时分秒）、类型（支出/收入）
- 日期选择器默认只显示年月日，可展开到时分秒
- 保存 → 写入 SQLite

### 3. AI 录入
- 文本输入框
- "AI 解析"按钮 → 调 Python 引擎 → 显示解析结果
- 解析结果展示：金额、分类、备注、时间
- 操作：确认保存 / 修改 / 取消

### 4. 统计
- 月度分类占比（饼图）
- 每日支出趋势（折线图）
- 支持切换月份

### 5. 设置
- 分类管理（列表展示，添加/编辑/删除分类）
- 数据管理：导出 JSON / 导入 JSON
- AI API 配置：API Key、接口地址
- 主题选择：浅色 / 深色 / 跟随系统
- 字号选择：小 / 中 / 大

## AI 解析引擎设计

### 流程

```
用户输入 → 预处理（去标点、提取金额）→ 关键词分类 → 
  全部匹配 → 结构化结果 → 回 Flutter
  部分匹配 → AI API → 结构化结果 → 回 Flutter
```

### 时间处理
- 描述中未提及时间 → timestamp 只存到日期级别（当天 00:00:00）
- 提到"今天中午/昨晚/昨天"等 → 尝试解析并记录具体时间

### AI API 触发时机
以下任一情况触发 AI API：
1. 金额提取失败（未匹配任何金额模式）
2. 分类关键词匹配到 0 个或匹配到 2 个以上
3. 用户主动点击"AI 智能解析"按钮

### 解析失败回退
AI API 也无法完整解析时（缺少金额、分类等必填字段），弹窗显示当前解析结果中已有的字段，并用输入框逐一询问缺失字段。用户补充完整后确认保存。

## 文件导入/导出

### 导出格式 (JSON)

```json
{
  "version": 1,
  "export_time": "2026-05-21T13:00:00",
  "categories": [...],
  "transactions": [...]
}
```

### 导入流程
选择 JSON 文件 → 校验格式 → 分类自动补齐 → 去重（金额+时间+备注相同则跳过）→ 写入数据库 → 显示导入结果

## 非功能性需求

- 数据全部本地存储，无云端同步
- 无需登录
- 导出文件可通过系统分享发送到另一台设备
- AI API 需联网，规则解析完全离线
